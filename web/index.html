    Convert with the native tool

    can be converted by Spark's native build-lod on this computer. It uses the same settings and has no browser memory limit. The result, , is saved next to the original file.

    The native converter downloads aren't published yet, so the one-click converter isn't available. You can still build build-lod yourself from Spark's repository and use the command below.

    1. Move the downloaded .bat file into the folder that holds your splat file. If you skip this, it asks you to pick the file.
    2. Double-click it. If Windows shows a blue “Windows protected your PC” box, click More info, then Run anyway.
    3. The first run downloads the converter (about 15 MB). When it finishes, the folder opens with the new .rad selected.
    1. Double-click the downloaded .zip to unzip it, then move the .command file next to your splat file. If you skip this, it asks you to pick the file.

    3. The first run downloads the converter (about 15 MB). When it finishes, Finder shows the new .rad.
